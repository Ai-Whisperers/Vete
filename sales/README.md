# Vete Sales Tracking

## Files

- `prospects.csv` — Master list of potential clinic customers

## Prospect Status Values

| Status | Description |
|--------|-------------|
| Not Contacted | New lead, no outreach yet |
| Contacted | Initial message sent |
| Responded | They replied (positive or negative) |
| Demo Scheduled | Meeting/demo booked |
| Demo Done | Demo completed |
| Trial | Using free trial |
| Negotiating | Discussing terms |
| Won | Paying customer 🎉 |
| Lost | Declined or no response |

## Priority Levels

- **High** — Large clinic, premium area, or warm lead
- **Medium** — Standard prospect
- **Low** — Small clinic or long-shot

## How to Use

1. Add new prospects to `prospects.csv`
2. Update Status and Last Contact after each touchpoint
3. Set Next Action for follow-up
4. Review weekly to ensure follow-ups happen
