# Vete README

## Introduction
Vete is a multi-tenant veterinary SaaS platform built with Next.js, Supabase, and TypeScript.

## Setup
To get started, follow these steps:

1. Clone the repository: `git clone https://github.com/vete/vete.git`
2. Install dependencies: `npm install`
3. Create a Supabase instance and set up environment variables
4. Run the development server: `npm run dev`

## Features
- Multi-tenancy support
- User management
- Appointment scheduling
- Patient management
- Invoice management
- Lab order management
