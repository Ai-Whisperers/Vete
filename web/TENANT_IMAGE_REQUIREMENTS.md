# Tenant Image Requirements Guide

This document lists all images needed for each tenant, where to place them, how to name them, and detailed prompts for creation.

---

## Directory Structure

All branding images go in:
```
web/public/branding/[tenant-slug]/images/
```

---

## Image Naming Convention

```
[tenant]-[category]-[name].[ext]

Examples:
- terrapet-hero-main.jpg
- terrapet-about-team.jpg
- terrapet-services-consultation.jpg
- dayah-portfolio-romance-001.jpg
```

## How to Use This Guide

1. **For AI Image Generation**: Copy the "Prompt" column and use with Midjourney/DALL-E/Stable Diffusion
2. **For Photographers**: Use the prompt as a brief description for the shoot
3. **For Placement**: Save images to the paths specified
4. **For Code**: The code is already updated to look for these paths
