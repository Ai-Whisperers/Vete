# ADR-001: Use Next.js 15 for Frontend
## Status
Accepted

## Context
We need to choose a frontend framework for our web application. Next.js 15 is a popular and widely-used framework that provides a lot of features out of the box.

## Decision
We will use Next.js 15 as our frontend framework.

## Consequences
Using Next.js 15 will provide us with a lot of benefits, including:
* Server-side rendering
* Static site generation
* Internationalization
* Routing
* API routes

However, it may also introduce some complexity and require additional setup.
