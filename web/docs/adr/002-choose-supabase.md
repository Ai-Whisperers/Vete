# ADR-002: Choose Supabase for Backend
## Status
Accepted

## Context
We need to choose a backend platform for our web application. Supabase is a popular and widely-used platform that provides a lot of features out of the box.

## Decision
We will use Supabase as our backend platform.

## Consequences
Using Supabase will provide us with a lot of benefits, including:
* Realtime database
* Authentication
* Authorization
* API

However, it may also introduce some complexity and require additional setup.
