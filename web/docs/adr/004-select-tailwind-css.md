# ADR-004: Select Tailwind CSS for Styling
## Status
Accepted

## Context
We need to choose a CSS framework for our web application. Tailwind CSS is a popular and widely-used framework that provides a lot of features out of the box.

## Decision
We will use Tailwind CSS as our CSS framework.

## Consequences
Using Tailwind CSS will provide us with a lot of benefits, including:
* Utility-first approach
* Customizable
* Responsive design

However, it may also introduce some complexity and require additional setup.
