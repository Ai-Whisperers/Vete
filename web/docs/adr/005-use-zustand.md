# ADR-005: Use Zustand for State Management
## Status
Accepted

## Context
We need to choose a state management library for our web application. Zustand is a popular and widely-used library that provides a lot of features out of the box.

## Decision
We will use Zustand as our state management library.

## Consequences
Using Zustand will provide us with a lot of benefits, including:
* Simple and easy to use
* Scalable
* Compatible with React

However, it may also introduce some complexity and require additional setup.
