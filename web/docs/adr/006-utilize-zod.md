# ADR-006: Utilize Zod for Validation
## Status
Accepted

## Context
We need to choose a validation library for our web application. Zod is a popular and widely-used library that provides a lot of features out of the box.

## Decision
We will use Zod as our validation library.

## Consequences
Using Zod will provide us with a lot of benefits, including:
* Simple and easy to use
* Powerful validation features
* Compatible with TypeScript

However, it may also introduce some complexity and require additional setup.
