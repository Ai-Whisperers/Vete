# ADR-009: Implement Authentication with Supabase
## Status
Accepted

## Context
We need to implement authentication in our web application. Supabase provides a built-in authentication system that we can use.

## Decision
We will use Supabase's built-in authentication system to implement authentication in our web application.

## Consequences
Using Supabase's authentication system will provide us with a lot of benefits, including:
* Improved security
* Easy user management
* Compatible with our backend platform

However, it may also introduce some complexity and require additional setup.
