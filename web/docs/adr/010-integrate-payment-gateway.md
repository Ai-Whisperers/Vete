# ADR-010: Integrate Payment Gateway
## Status
Accepted

## Context
We need to integrate a payment gateway in our web application. This will allow us to process payments and subscriptions.

## Decision
We will integrate a payment gateway using Stripe.

## Consequences
Using Stripe will provide us with a lot of benefits, including:
* Improved payment processing
* Easy subscription management
* Compatible with our backend platform

However, it may also introduce some complexity and require additional setup.
