## How to Create a New ADR
To create a new ADR, follow these steps:
1. Create a new Markdown file in the `docs/adr` directory.
2. Use the following template:
# ADR-XXX: [Title]
## Status
[Proposed | Accepted | Rejected]

## Context
[Description of the context]

## Decision
[Description of the decision]

## Consequences
[Description of the consequences]
3. Replace `XXX` with the next available number.
4. Fill in the template with the relevant information.
