# API Versions

## Overview

The Vete API is versioned to ensure stability and backwards compatibility.

## Current Versions

* **v1**: Initial version of the API
* **v2**: Latest version of the API with new features and improvements

## Deprecation Notices

* **v1**: Will be deprecated in 6 months
* **v2**: Is the recommended version for new integrations
